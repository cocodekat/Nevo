# Nevo

This repository contains two separate Nevo implementations:

- [`compiler/`](compiler/) Silicon ARM64/x86_64 compiler. It remains independent and is not part of the transpiler layout.
- [`transpiler/`](transpiler/) is the portable C transpiler, organized for separate macOS and Windows distribution work.

See the README in each implementation folder for its own build and development details. Documentation for the transpiler is outdated and discontinued.
